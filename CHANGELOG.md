# Changelog

## 0.2.0 - 2026-11-08

### Added

- Added 15 handbook-aligned and current-context questions covering the Irish famine, the Factories Act 1847, David Hume, the Boer War, constitutional institutions, MPs' responsibilities and the current Prime Minister.
- Added five short lessons for current test-day guidance, Victorian social change, the Scottish Enlightenment, constitutional institutions and current UK office holders.
- Added a dated validation gate for time-sensitive facts.

### Changed

- Current-context questions are kept out of handbook mock exams.
- Question-bank documentation now states the verified total of 1,611 questions and distinguishes official handbook content from current context.

### Fixed

- Filled factual coverage gaps identified against the supplied 2026 practice material.
- Replaced stale assumptions about the current Prime Minister with the GOV.UK office holder reviewed on 8 November 2026.
- Fixed `npm start` returning 404 for the built app when `NODE_ENV` was not set in the launching shell.

### Removed

- No user-facing features were removed.

### Security

- No security changes are included in this release.

### Not included

- This release does not reproduce the confidential official question bank or claim that unofficial practice questions are official exam questions.
- This release does not include a package publication, deployment configuration change or remote version tag.
